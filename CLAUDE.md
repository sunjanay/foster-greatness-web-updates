# Project Context

## What This Is

This is a **widget embed** for the main Foster Greatness website. It displays updates, events, and donation opportunities that get embedded into the main site.

## Important Context

- **No page headers needed** - The main website provides site context and navigation
- **No hero sections** - This content is embedded within existing pages
- **Focus on the content cards** - Updates, events, newsletter, and community sections
- The `/updates` route content is now the home page (`/`)
- Data is managed through `data/updates.json`

## When Improving UX/Design

Focus on:
- Card design and layout
- Link label specificity (front-load keywords)
- Visual hierarchy within cards
- Spacing and typography
- Color usage per brand guidelines

Do NOT:
- Add page headers or hero sections
- Add site navigation
- Add footer content
- Add standalone page context
- **EVER modify quotes** - Quotes are attributed to real people and must never be changed

## Brand Guidelines

Follow the Foster Greatness brand system:
- Colors: Navy (#1a2949), Teal (#0067a2), accents
- Typography: Century Gothic
- Voice: Authentic, empowering, dignity-centered
- No charity/deficit language
